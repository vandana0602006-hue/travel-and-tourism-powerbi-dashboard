# Travel and Tourism Data Analysis Dashboard

## Project Overview

This project focuses on analyzing travel and tourism data using Microsoft Excel and Power BI. The goal is to transform raw data into meaningful insights through interactive data visualizations.

## Tools Used

* Microsoft Excel
* Microsoft Power BI

## Project Workflow

1. Imported the travel and tourism dataset.
2. Checked the dataset for missing values and duplicate records.
3. Prepared the data for analysis.
4. Created an interactive dashboard in Power BI.
5. Used visualizations to present insights from the dataset.

## Dashboard

The dashboard provides a visual overview of the travel and tourism data.

## Project File

The Power BI dashboard file (`.pbix`) is available in this repository. Download it and open it using Microsoft Power BI Desktop to explore the report.
